# Library Management System - Web Version

Stack: Java 17, Spring Boot, Thymeleaf, JDBC (Spring JdbcTemplate), MySQL, HTML/CSS.

1. Install JDK 17+ and MySQL.
2. Run database.sql in MySQL Workbench.
3. Edit application.properties and replace `your_mysql_password`.
4. Open the project as Maven.
5. Run `com.library.LibraryApplication`.
6. Open http://localhost:8080

Login: admin / admin123

All book/member/issue/return operations use the MySQL database through JDBC/JdbcTemplate.
